# Week 1 Day 1 - DevOps Basics

## 🌐 How the Internet Works
- Internet is a network of connected computers
- Each device has an IP address
- DNS converts domain names to IP addresses
- Data travels in packets
- Uses HTTP/HTTPS protocols

Flow:
Browser → DNS → Server → Response

---

## 🖥️ What is a Server?
- A server provides services/data to clients
- Works 24/7
- Stores websites and applications

Examples:
- Web server
- Database server
- File server

---

## 🔁 Web Server vs Application Server

### Web Server
- Serves static content
- Handles HTTP requests
- Examples: Nginx, Apache

### Application Server
- Runs business logic
- Generates dynamic content
- Connects to databases
- Examples: Tomcat, Node.js

Web server = Delivery
App server = Logic
